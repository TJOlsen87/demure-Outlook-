# Changelog

## 1.1.1 - First public release

- Announce new mail with account, sender, and subject, without reading the message body.
- Review the last five notifications with Ctrl+Alt+Shift+O, newest first.
- Keep history in memory for the current NVDA session.
- Connect to running classic Outlook without requiring it to receive focus first.
- Retry every 15 seconds while Outlook's automation interface is unavailable.
- Preserve the existing quiet-period email sound and duplicate-event filtering.

Validated with 12 automated regression tests and user testing on NVDA 2026.2.

## Earlier local versions

- 1.1.0: Added the five-notification history dialog and shortcut.
- 1.0.1: Concise new-mail announcements and a sound after a quiet period.
